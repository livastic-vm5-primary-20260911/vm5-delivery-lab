Boundaries that protect users

What this tool does and does not verify

This checker accepts only Base chain ID 8453, a successful mined transaction receipt, the native Circle USDC token contract, a well-formed ERC-20 Transfer event, and an exact recipient/atomic amount match. It uses tx_hash:log_index to distinguish events in the same transaction. A match against an RPC-designated finalized block is labeled as such, not presented as legal or accounting proof.

It does not check who owns a wallet, map transfers automatically to real invoices, catch sanctions, validate exchange deposits, handle fiat off-ramps, value tokens for taxes, or protect against fraudulent invoices. It does not require MetaMask, authenticate an account or hold/send funds. Only one public RPC is queried; no fallback when access is restricted or unavailable.

If you want to compare your own invoice and self-reported export CSVs with zero external network calls, use the separate free offline CSV candidate matcher. Its synthetic transactions are deliberately fake; never use them here as real onchain examples.
