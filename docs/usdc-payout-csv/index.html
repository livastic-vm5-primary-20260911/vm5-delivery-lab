Live original tool

Paste CSV or open a local file.

Required columns are address,amount; optionally include chain,token,memo. Column names are case-insensitive. Amount is decimal USDC (not atomic units). Any file you choose is read on your own device and never uploaded by this page.

Maximum 64 KiB UTF-8, 500 data rows, 8 columns. No seed phrases, private keys, confidential client records or passwords. Only review recipient data you are authorized to handle.

What this catches

Invalid or zero EVM addresses, duplicate payees ignoring address case, invalid/zero/negative amounts, more than six fractional digits, wrong chain or token, ragged CSV rows and formula-like cells.

Exact math: totals use integer USDC atomic units — not floating point — and count only independently valid unique rows. A partial total is not the amount to pay.

No sensitive output: downloaded findings list diagnostic codes and row/column numbers, not payee addresses or raw spreadsheet content.

We intentionally do NOT generate unsigned transfers, ERC-20 approvals, transaction data, EIP-3009 signatures or wallet deep links.

    Limitations and trust

    Check the data. Confirm the payment separately.

    The program validates address format, not EIP-55 checksum validity or address ownership. It cannot check address sanctions, lost wallets, wrong beneficiaries, chain state, gas, token balances, recipient promises, transaction settlement or contract risk. No automatic payout or financial advice is provided.

    We deliberately limit input size to 64 KiB and 500 rows. The parser recognizes CSV quotes, escaped quotes and embedded line breaks. Diagnostic export contains only row/column positions and issue types, excluding entered wallet addresses and cell values. No tracking, telemetry, wallet RPC, external scripts or uploads are used.

    For larger or regulated distributions, obtain independent checks, legal/compliance review and an actual sender-wallet transaction simulation before approving any payment. See the official x402 HTTP transport for payment-protocol details and Circle's USDC information.
