A correct HTTP 402 is an unsigned payment quote, not payment, paid-handler delivery, verification of a customer's signed transaction, an SLA or proof of revenue. Probes can become stale. If a request timed out, the result is inconclusive, not automatically an outage.

METHOD AND LIMITATIONS

What this test actually checks.

1 · API health

Does the actual public merchant answer an unsigned health request and declare Base as its network?

2 · Correct input

Does a two-row completely invented CSV request return an x402 v2 payment quote? Missing or malformed POST bodies may legitimately return HTTP 400 rather than 402.

3 · Verify the quote

Are chain ID, official Base Circle USDC token, the original payee and each advertised micro-USDC amount consistent? We never sign, pay or test settlement.
