OPERATIONS, NOT ACCOUNTING AUTOMATION

What this checker refuses to assume.

Funding is not fulfillment.

A processor can hold fiat while beneficiary payments remain pending, rejected or returned. Payout ID and final reported status need to be matched separately from the initial bank debit.

Amounts need their currencies.

An EUR funding amount is not numerically comparable to USDC/USDT received. Missing rate, fee, currency and timestamp evidence stays an explicit review item.

A row is not a transaction.

These CSVs are operator-reported and can be wrong, incomplete or manipulated. A reported “paid” record is not automatically verified on-chain. Keep original bank, invoice, provider and reviewer evidence.

Export safely.

The downloaded exception CSV intentionally contains only input type, row number and exception code. It does not include bank amounts, invoice IDs, wallets, names or recipient details.
