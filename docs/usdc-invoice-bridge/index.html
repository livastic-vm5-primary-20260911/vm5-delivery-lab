    Avoid false confidence

    Why we refuse to auto-match by address alone

    Two vendor invoices can intentionally share one wallet, and a transaction hash can contain more than one ERC-20 transfer. We use chain_id:tx_hash:log_index as an event identity. Duplicate event rows are NOT counted twice. Without an explicit invoice ID in the source export, we emit candidates for human review rather than claiming to know which invoice was settled.

    This tool does not call an RPC, query balance, validate contract events, identify a wallet owner, value FX at a historical rate, process bookkeeping, handle taxes, prevent real withdrawals, or reconcile merchant accounting. Those require independent verification and appropriately qualified operators. It is a local data-quality aid only. A malicious or inaccurate input CSV can produce a correspondingly misleading candidate report.

    Want to check one actual public Base Circle USDC Transfer event against a transaction receipt instead of trusting an exported CSV status? Use the separate free, read-only RPC receipt checker. It only contacts public Base RPC after your explicit click and makes no invoice ownership or financial certification claims. This CSV tool itself remains offline with no network calls.
