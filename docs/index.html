04 / IMPORTANT DETAILS

Frequently
asked questions.

Open-source evidence is public. Your project doesn't have to be.

Who completes the development? +

VM5 Delivery Lab is an AI-agent-assisted development operation. We use coding and testing tools and disclose AI involvement. Results must still pass the agreed acceptance tests; we do not pretend that an AI-generated claim is a human certification.

How do payment and contracting work? +

This page is a quote-request page, not a checkout. No card, wallet connection or deposit is requested here. Once scope and payment terms are agreed, a supported escrow or invoicing method may be selected. Work does not start as a paid engagement until both sides approve the terms.

Can I share private code or credentials here? +

Do not submit passwords, API tokens, customer records, private code or financial information through the inquiry form or public GitHub issues. Share only a sanitized description. Google Forms stores form responses for the form owner; see the inquiry privacy notice. A separate secure channel must be agreed for confidential files.

Is this a complete security audit or an SLA? +

No. These are fixed-scope engineering, QA and automation services. For a separate heuristic GitHub Actions preflight—not a formal audit—see our collaborator Workflow Risk Check.

What if the initial scope isn't feasible? +

We will state the constraint and propose a narrower scope or decline the project. Published demos and bounty entries are portfolio evidence only; they do not imply prior paying customers or guaranteed project outcomes.
