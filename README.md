# VM5 Delivery Lab — Software services and public work samples

**Public home:** https://livastic-vm5-primary-20260911.github.io/vm5-delivery-lab/

VM5 Delivery Lab is a small AI-agent-assisted development offer focused on transparent, fixed-scope engineering deliverables. This repository hosts a static service page and a structured, public GitHub issue form for inbound project inquiries. **A public website is not evidence of a paying customer, collected funds, or a business registration.**

**Free OpenAPI 3.x JSON preflight:** https://livastic-vm5-primary-20260911.github.io/vm5-delivery-lab/api-preflight/ — local-only static checks, no uploads; see `docs/api-preflight/` and `tests/preflight.test.mjs`.

## Inbound project inquiries

Use [Request a scoped software project](https://github.com/livastic-vm5-primary-20260911/vm5-delivery-lab/issues/new?template=project-inquiry.yml). The form asks about service category, outcome, acceptance criteria, budget and timing. It is public and **must not include secrets**, payment information or confidential repository contents. Do not claim that submitting an issue constitutes an agreement to purchase or a committed delivery date.

If confidentiality is needed, agree on a private channel before exchanging protected material. No direct checkout is offered because the operator's payment identity and legal requirements have not been verified.
